# Daily Shorts engine

Automated pipeline for the daily YouTube Shorts. **Not part of the website** — this branch (`youtube-pipeline`) only holds the video engine.
Start with `RUNBOOK.md` (v2: real facts + real NASA images, built around YouTube's monetization policies).
Reference scenes: `scenes/moon_footprints/` (real photos) and `scenes/moon_10x_closer/` (animation).

Open-source / public-domain pieces: Piper TTS (rhasspy/piper, MIT) with the LibriTTS voice (CC BY 4.0), Playwright (Apache-2.0),
FFmpeg, Geist font (OFL), NASA images from github.com/nasa/NASA-3D-Resources (public domain), Natural Earth II world map
(public domain, via CesiumJS), Moon maria layout from CesiumJS (Apache-2.0).
