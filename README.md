# What-If Shorts engine

Automated pipeline for the daily YouTube Shorts. **Not part of the website** — this branch (`youtube-pipeline`) only holds the video engine.
Start with `RUNBOOK.md`. Reference scene: `scenes/moon_10x_closer/`.

Open-source pieces: Piper TTS (rhasspy/piper, MIT) with the LibriTTS voice (CC BY 4.0), Playwright (Apache-2.0), FFmpeg,
Geist font (OFL), Natural Earth II world map (public domain, via CesiumJS), Moon maria layout from CesiumJS (Apache-2.0).
